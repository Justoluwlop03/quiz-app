# Group review copies

Each member folder contains copies of the assigned files. The runnable application stays in the project root; these packets are for review. Ask each reviewer to provide comments or suggested edits, then compare those with the originals before merging changes.

1. `Member_1_Admin_Dashboard`: `templates/admin/dashboard.html` — admin dashboard.
2. `Member_2_Quiz_Pages`: `templates/index.html`, `templates/quiz.html`, `templates/result.html`, and `templates/base.html` — page layout and quiz flow screens.
3. `Member_3_Quiz_Logic`: `services/quiz_generator.py` and `services/scoring.py` — quiz creation and scoring.
4. `Member_4_PDF_Parser`: `services/pdf_parser.py` — PDF question extraction.
5. `Member_5_App_Routes`: `app.py` — Flask routes and application setup.
6. `Member_6_Tests_And_Styling`: `tests/` and `static/css/style.css` — automated checks and visual styling.

These copies can become outdated if the root project changes. Do not add `.env`, the virtual environment, or the database to these folders.
